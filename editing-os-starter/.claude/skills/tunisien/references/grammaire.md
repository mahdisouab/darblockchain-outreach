# Grammaire de décodage — comprendre une phrase tunisienne sans passer par le français

Ce fichier ne cherche pas l'exhaustivité : il donne les mécanismes qui permettent de
**segmenter** un mot inconnu (préfixe + racine + suffixe) et de suivre la structure d'une
phrase orale. Provenance : ★ = attesté dans le corpus ou dans les vidéos du créateur ;
sans étoile = tunisien général, à corriger si le créateur dit autrement.

## 1. Pronoms et suffixes (la clé de la plupart des mots « inconnus »)

| Personne | Indépendant | Suffixe possessif / objet | Sur préposition | Datif (verbe + « à ») |
|---|---|---|---|---|
| je | ena / eni | -i (5edmet-i), -ni (objet : 9ol-li → 9olli) | 3and-i, m3a-ya, li-ya, fi-ya | -li : nab3ath-li |
| tu | enti | -ek ★ (mte3-ek, profil-ek, rou7-ek, serr-ek) | 3and-ek, m3a-k, li-k, 3li-k, bi-k | -lek ★ : n9oul-lek, nab3ath-lek, ya3ti-lek |
| il | houa | -ou / -h ★ (mte3-ou, esm-ou, ghadhab-ou, 3and-ou) | 3and-ou, m3a-h, fi-h, 3li-h | -lou : ta7ki-lou ★ |
| elle | hia | -ha ★ (mte3-ha, 3ommal-ha, 3omr-ha) | 3and-ha, m3a-ha, fi-ha | -lha |
| nous | a7na | -na ★ (mte3-na, 5edmet-na, 7yet-na, lezem-na) | 3and-na, m3a-na | -lna |
| vous | entouma | -kom ★ (mte3-kom, men-kom) | 3and-kom, bi-kom | -lkom |
| ils | houma | -hom ★ (mte3-hom, rou7-hom, nafs-hom) | 3and-hom, men-hom, fi-hom | -lhom |

Lecture d'un mot : `ya3rfouhomch` = y- (ils) + a3rf (savoir) + -ou (pluriel) + -hom (les) +
-ch (négation) → « ils ne les connaissent pas ». `nab3athlek` = n- (je) + ab3ath (envoyer) +
-lek (à toi). Toujours découper avant de déclarer un mot inconnu.

## 2. Le verbe

**Inaccompli (présent / futur / général)** — préfixes ★ :

| | singulier | pluriel |
|---|---|---|
| 1re | **n**-e5dem (je travaille), **n**-a3ref, **n**-9oul | **n**-…-**ou** : ne5dmou, n9oulou ★, nesta3mlou ★, najmou ★ |
| 2e | **t**-e5dem, **t**-a3ref ★, **t**-esta3mel ★, **t**-najem ★ | **t**-…-**ou** : te5dmou, ta3rfou |
| 3e m. | **y**-e5dem ★, **y**-a3ref ★, **y**-najem ★, **y**-esta3mel ★ | **y**-…-**ou** : ye5dmou ★, yesta3mlou ★, y5afou ★, ynajmou |
| 3e f. | **t**-… (comme « tu ») : tnajem ★ (elle peut), ta7kem ★ | — |

Attention : `t-` = « tu » **ou** « elle ». `tnajem ta3mel des erreurs` = tu peux faire ;
`el technologie hedhi tnajem t2athar` = elle peut influencer. Le contexte décide.

**Accompli (passé)** — suffixes : -t (je / tu : ktebt ★ j'ai écrit / tu as écrit, kont ★
j'étais, fhemt), -et (elle : saret ★ est arrivée, mna3et ★ a interdit), -ou / -aw (ils :
basou ★, 3taw ★ ils ont donné, 9alou), -na (nous : wallina ★ nous sommes devenus, fhemna),
-tou (vous).

**Impératif** ★ : ekteb (écris), rod belek (fais attention), 5alli (laisse / garde), chouf
(regarde), esma3 (écoute), a3tini (donne-moi), 5oudh (prends), 7ott (mets), 9olli (dis-moi).

**Participes / adjectifs verbaux** ★ : mertah (à l'aise), ma7miya (protégée), m3allem,
mkharrej (diplômé), ma5doum, dangereuse / simple (français, invariable ou accordé à
la française).

**Périphrases de temps et d'aspect** :

| Forme | Sens | Exemple ★ |
|---|---|---|
| **bech** + inaccompli | futur, intention, but | bech na3mel video · nesta3mlouh bech ne5dmou · dima bech tkoun fi saffek |
| **kont bech** + inaccompli | j'allais / je voulais | kont bech n9oullek |
| **9a3ed** + inaccompli | en train de | 9a3ed ne5dem 3la… |
| **wallina / wallit / walla** + inaccompli | on en est venus à, désormais on | wallina n9oulou kol chay lel AI |
| **3omr-** + ma + verbe (+ch) / 3omrha la | jamais | l'IA 3omrha ma ta7kemch 3lik |
| **mazel** + inaccompli / mazelt | encore, toujours | mazel yesta3mlou |
| **ynajem / tnajem / nnajem / najmou** + inaccompli | pouvoir, possibilité, risque | ynajem ykoun a5tar · tnajem ta3mel des erreurs |
| **lezem / lezemna / lezmek** + inaccompli | il faut | lezem trod belek · lezemna nefhmou |
| **n7eb / t7eb / y7eb** + inaccompli | vouloir | n7eb el chiffre yodhher kbir |
| **3andi / 3andek / 3andou** + nom | avoir | 3andi PFE · 3andek sou2el · 3andou mochkla |

## 3. La négation

`ma` + verbe + `ch` ★ : ma na3refch, ma fhemtch, ma yesta3mlouch, ma yjaweb**ch**,
ma yousal**ch**, ma yefhem**ch**, ma ya3rfou**ch**.

Sur les pseudo-verbes : `ma 3andich` / `ma 3andekch` (je n'ai pas), `ma famech` /
`ma fammech` ★ (il n'y a pas), `ma fammech 7atta plateforme` (il n'y a même pas une…),
`manich` (je ne suis pas), `makch` (tu n'es pas), `mahouch` ★ / `mahich` ★ / `mahomch`
(il / elle / ils … n'est pas) — ces derniers portent souvent un attribut français :
`mahouch juste un problème technique`, `mahich 7aja jdida`.

`7atta` + négation = « pas même » : `w 7atta wa7ed ma yjaweb` (et pas un seul ne répond).
`ken` après négation = « seulement » : `el mochkla mahich ken fel étudiants`.
`la … la` = ni … ni. `ma …ch 3ad` = ne … plus.

## 4. Les mots-outils qui structurent la phrase

| Mot | Sens / fonction | Exemple |
|---|---|---|
| **elli** ★ | que, qui, ce que — relatif universel, aussi complétive après na3ref | na3ref elli barcha menkom… · les CAPTCHA elli kol mara y9ollek… |
| **ki** ★ | quand, lorsque ; « ki + inaccompli » = condition-temps | ki testa3melha sans comprendre… · ki ta3mel copy-coller |
| **kif** ★ | comme, comment (kif kif = pareil) | kifech / kif ta3mel |
| **ken / kan** ★ | si ; seulement | ken testa3mel Claude fil PFE mte3ek… · ken 3andek sou2el |
| **5ater / 3la 5ater** ★ | parce que | 5ater l7a9… |
| **ama** ★ | mais | el produit behi ama el marketing dha3if |
| **w** ★ | et ; démarre aussi une phrase (w hné, w surtout) | w hné lezem trod belek |
| **donc** ★ · **alors** · **juste** · **déjà** · **surtout** · **sans** · **même** · **par exemple** · **franchement** · **normalement** · **direct** | connecteurs français intégrés | donc lezem trod belek · sans ma ta3ref |
| **hné / houni** ★ | ici ; « w hné » = et là (transition) | w hné el mochkla |
| **tawa** ★ | maintenant (souvent « de nos jours ») | tawa presque kol we7ed yesta3melha |
| **ba3d / ba3d ma** ★ | après / après que | ba3d ma 3taw données confidentielles |
| **9bal / 9bal ma** ★ | avant / avant que | 9bal ma y9rah insan |
| **7atta** ★ | même, jusqu'à, aussi (« 7atta Samsung ») | 7atta 7ajet intimes |
| **zeda / zada** | aussi | w enti zeda |
| **dima** ★ | toujours | dima bech tkoun fi saffek |
| **mahma** ★ | quoi que | mahma t9oul |
| **ya3ni** | c'est-à-dire, je veux dire (tic oral coupable) | — |
| **ya5i** | donc / n'est-ce pas (attaque de question) | ya5i chnowa el 7all ? |
| **bark** | seulement | 5oudh wa7ed bark |
| **bel7a9 / l7a9** ★ | vraiment, à vrai dire | 5ater l7a9 |
| **mel a5er / mel lou5er** ★ | bref, au final | mel a5er, kont bech n9oullek |
| **3alle5er** ★ | à fond, au maximum | design 3alle5er |
| **hakka** ★ | comme ça | hakka ya3mel |
| **hedha / hedhi / hedhom** ★ | ce, cette, ces (après le nom : el logiciel hedha) | el technologie hedhi |
| **fama / famma** ★ | il y a (présentatif) | fama 7aja lezem ta3refha · famma rajel |
| **chnowa / kifech / 3lech / chkoun / win / wa9tech / 9addech / chbih** ★ | quoi / comment / pourquoi / qui / où / quand / combien / qu'a-t-il | 3lech ? · chkoun y9ra el CV ? |

## 5. Constructions à lire comme des blocs

- **Question-hook** : `X mte3na fi A ynajem ykoun a5tar men Y fl B ?` — comparaison
  inattendue + question, sans « est-ce que ».
- **Topic puis commentaire** : `el CV mte3ek, ma yousalch lel recruteur` — le sujet est
  posé d'abord, la prédication vient après (le français inverserait).
- **Chaîne d'inaccomplis** : `ynajem ykoun`, `t7awel tal9a`, `bech t7ess rou7ek mertah` —
  pas d'infinitif, chaque verbe se conjugue.
- **Verbe + datif + objet** : `n9oullek 7aja`, `nab3athlek el template`, `ya3tik zéro`.
- **Possession** : `mte3` + suffixe après le nom (`PFE mte3hom`), ou état construit
  (`5edmetna`, `7yetna`, `esmou`) — les deux coexistent ; on ne remplace pas l'un par
  l'autre.
- **Pluriels** : arabes internes (7aja → 7ajet, mochkla → machekel, rajel → rjel, kbir →
  kbar ★ « parties kbar ») ou français intacts (les données, les candidats, des erreurs).
- **Intensité** : barcha ★ (beaucoup, très : dangereuse barcha), yesser / b-yesser ★ (de
  loin : a5tar b-yesser), 3alle5er ★, chwaya (un peu), ta9riban / presque ★.
- **Réflexif** : rou7-ek / rou7-ou / rou7-hom ★ (t7ess rou7ek mertah · basou rou7hom 3la…) ;
  bidek (par toi-même) ; wa7dek (seul).

## 6. Ce qui diffère du français et du MSA (pour ne pas « corriger » à tort)

| Le tunisien fait… | Ne pas y voir une faute |
|---|---|
| pas de « est-ce que » : question par intonation ou mot interrogatif final | `ta3ref les CAPTCHA … ?` |
| pas d'infinitif : deux verbes conjugués à la suite | `t7awel tal9a` = elle essaie de trouver |
| `elli` pour tous les relatifs, `elli` après « savoir » | `na3ref elli` = je sais que |
| négation encadrante `ma … ch` | pas un « ch » parasite |
| `bech` = futur ET but | `bech ye5dmou` = pour travailler / ils vont travailler |
| `ki` = quand, `ken` = si, `kif` = comme | trois mots proches, trois sens |
| adjectif français non accordé ou accordé au hasard | `7ajet intimes`, `7yetna personnelle`, `données confidentielles` |
| article `el` devant un mot français, `les` conservé | `el logiciel`, `les décisions mte3na` |
| nombre en français ou en arabe selon l'élan | `50 entreprise` (5amsin) · `100 %` (cent pour cent) · `2025` (deux mille vingt-cinq) |
| MSA absent : ni `sawfa`, ni `laysa`, ni `hunaka`, ni `kayfa`, ni `madha` | `bech`, `mahouch`, `fama`, `kifech`, `chnowa` |
